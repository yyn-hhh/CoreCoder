【公司内部 Python 安全与研发规范 V1.0】

1. 异常处理规范：禁止直接使用裸的 except: 或 except Exception 捕获异常。必须明确捕获具体的异常类型（如 ValueError, KeyError），并在捕获后记录日志（使用 logging 模块，禁止使用 print）。

2. 字典取值规范：从字典中获取可能不存在的键时，必须使用 dict.get(key, default_value) 方法，严禁直接使用 dict[key]，以防止抛出 KeyError 导致服务崩溃。

3. 资源清理规范：所有涉及文件读写、网络连接、数据库会话的代码，必须使用 with 上下文管理器（Context Manager），禁止手动调用 close()，以防止资源泄漏。

4. 外部 API 调用规范：在调用第三方 API 或外部网络请求时，必须设置超时时间（timeout 参数），且超时时间不得设置超过 10 秒。

5. 依赖导入规范：严禁在代码中使用 from module import *。必须明确导入具体的类或函数。标准库、第三方库、本地模块的导入必须严格分组，组与组之间空一行。

6. 日志规范：生产环境的代码中绝对禁止使用 print 输出调试信息。必须统一使用 logging 模块，且日志必须包含时间戳和日志级别。

7. 函数命名规范：所有的内部辅助函数，必须以单下划线开头（如 _helper_function）。公共 API 函数名必须使用完整的英文单词，禁止使用拼音或缩写（如禁止使用 get_user_info_by_id 缩写成 get_usr_inf）。

8. 圈复杂度规范：单个函数的 if-elif-else 嵌套层级不得超过 3 层。如果超过，必须使用提前 return 或提取子函数的方式进行重构，严禁写出“箭头型”代码。
